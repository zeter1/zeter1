# Support and bug reports

Основные репозитории содержат структурированные GitHub Issue Forms для сообщений об ошибках. Они помогают сразу собрать данные, необходимые для воспроизведения проблемы.

## Перед созданием issue

1. Убедитесь, что проблема воспроизводится на текущем состоянии проекта.
2. Посмотрите README и документацию проекта.
3. Если приложение создаёт диагностические файлы — сохраните последнюю проблемную сессию до повторных запусков или очистки данных.
4. Уберите из логов и файлов личную информацию, секреты и данные, которые не должны быть публичными.

## Хороший bug report

Полезный отчёт обычно содержит:

- версию/ревизию приложения;
- версию Windows;
- точные шаги воспроизведения;
- фактический результат;
- ожидаемый результат;
- настройки, влияющие на сценарий;
- небольшой релевантный фрагмент диагностики;
- информацию о том, воспроизводится ли проблема повторно.

Вместо:

> программа не работает

намного полезнее:

> Windows 11 24H2, версия X. После выбора NVENC и системного звука запись запускается, но через 8–10 секунд FFmpeg завершается. CPU-кодирование при тех же параметрах работает. Приложен релевантный фрагмент diagnostic log.

## Что не следует публиковать

Никогда не публикуйте без необходимости:

- пароли;
- API-ключи;
- OAuth-токены;
- cookie;
- приватные ссылки;
- реальные crash dumps без предварительной проверки;
- личные документы, аудио и видео;
- полный каталог пользовательских данных приложения;
- логи, содержащие личную переписку или диктуемый текст.

## Диагностика в проектах

### Screen Recorder Pro

Особенно полезны параметры capture/encoding, аудиоустройства, FFmpeg context, тайминги и сведения о GPU/мониторе.

### BSOD Investigator

Полезны безопасная диагностическая сводка, версия CDB/WinDbg и сообщения о символах. Crash dump не следует автоматически публиковать в issue.

### VoiceFlow

Укажите модель Whisper, CPU/CUDA режим, compute type, микрофон и подсистему, где возникла проблема: hotkey, capture, inference или text insertion.

### Video Translator Pro

Укажите этап pipeline: Whisper, перевод, Edge TTS/gTTS, Pause Sync, FFmpeg, финальная проверка или recovery.

### ZeTer OS

Укажите desktop/web режим и конкретный модуль. Не прикладывайте рабочее состояние или backup с личными данными.

### Vacancy Parser Pro

Укажите источник вакансий, параметры запроса и безопасную сводку диагностической сессии.

### Universal Video Downloader

Укажите сайт, режим видео/MP3, качество, версию yt-dlp и релевантное сообщение FFmpeg/yt-dlp. Не публикуйте cookie и приватные URL.

### Text to MP3 for Windows

Укажите голос SAPI, сценарий чтения/MP3, аудиоустройство и безопасный фрагмент диагностики.

### Windows PC Locker

Укажите настройки предотвращения сна, таймер и последовательность lock/unlock. Для безопасной базовой проверки используйте встроенный `--self-test`.

## Security reports

Для потенциальных уязвимостей, где публикация деталей может создать риск, используйте инструкции из `SECURITY.md` соответствующего репозитория и сначала свяжитесь приватно.
